# Guild Dragon Bot v1.4

A button-based Discord guild dragon game.

## New in v1.4
- Keeper title system
- Daily streak system
- `/dragon_title`
- `/dragon_streak`
- Better profile cards
- Dragon stage titles
- Time-aware dragon mood
- Cleaner living dragon text
- Full project release

## Run

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python bot.py
```

## .env

```env
DISCORD_TOKEN=your_token_here
```

## Discord setup

```text
/dragon_setup
```

## Optional commands

```text
/dragon_name
/dragon_color
/dragon_profile
/dragon_title
/dragon_streak
/dragon_event_channel
/dragon_reset
```
