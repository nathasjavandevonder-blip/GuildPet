# Guild Dragon Bot

A button-based Discord guild pet / dragon minigame.

## Setup

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Create `.env`:

```env
DISCORD_TOKEN=your_token_here
```

Run:

```bash
python bot.py
```

In Discord:

```text
/dragon_setup
```
